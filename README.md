# 國泰基金安心看

這是一個給家人看的簡潔基金看板，顯示三檔國泰投信基金：

- 國泰中小成長基金
- 國泰大中華基金
- 國泰科技生化基金

## 資料來源

主要資料來源是 SITCA 投信投顧公會的「基金淨值（日）」。

網站啟動後會由 `server.js` 查詢 SITCA，抓取國泰投信公司代碼 `A0037` 的資料，再挑出這三檔：

- `T3703Y` 國泰中小成長基金-新台幣A(不配息)
- `T3706Y` 國泰大中華基金
- `T3707Y` 國泰科技生化基金

基金不是股票，所以這裡顯示的是每日更新的最新淨值，不是股票那種盤中即時成交價。

## 為什麼不需要資料庫

目前只需要顯示三檔基金的最新淨值，不需要登入、留言、保存使用者資料或長期歷史紀錄，所以不需要資料庫。

後端會暫存 SITCA 查詢結果 30 分鐘，減少重複查詢。

## 本機開啟

雙擊 `open-site.bat`，它會：

1. 產生網站檔案
2. 啟動本機網站
3. 打開 `http://localhost:3000`

## Render 部署

這個專案現在是 Node Web Service，不是 Static Site，因為前端需要透過後端查 SITCA。

Render 設定已放在 `render.yaml`：

- Build Command: `npm run build`
- Start Command: `npm start`
- Runtime: Node

部署後首頁會讀取 `/api/funds` 取得最新資料。

## 已測過但不採用

- TDCC OpenAPI：可連線，但查不到這三檔國泰境內基金。
- TPEX 開放式基金 API：可連線，但這三檔不在該 API 的當日行情資料內。
- 國泰投信公開頁：能在瀏覽器看到資料，但程式直接抓取容易遇到 403，不適合作為主要串接方式。
